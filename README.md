# license-oxygenoss

🔥 This repo provides the LICENSEs used in oxygen-OSS Projects.
Oxygen-OSS (Oxygen Open Source Software) is an Organization that provides users with Anti-Commercial and Custom LICENSEs used across Oxygen-OSS projects. Unlike most open-source licenses that allow corporate greed and exploitation, our licenses focus on **user-sovereignity**.

## 🎯 Our Philosophy
**Oxygen-OSS Creates FOSS/FLOSS software** by **traditional definitions, not the ones forced on by organizations like OSI that allow corporate exploitation.**

## ❓ The "Why?"
- **Kindness** - Built with Love ❤️
- **Community Protection** - We try to prevent *enshittification* of Software built **by the Community, for the Community**.
- **We hate Corporate Greed** - We think Corporate Greed *enshittifies* Software.
